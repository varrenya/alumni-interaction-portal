# Alumni Interaction Portal

A Flask-based student-alumni networking portal.

## Features
- Home, About, References and Alumni Directory pages
- Search alumni by name, company, role, location or skill
- View detailed alumni profiles
- Send a demo connection request
- Responsive Bootstrap interface

## Technologies
Python, Flask, HTML, CSS, JavaScript, Bootstrap

## Run
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000
